Akhlaq Malik

Hey, I’m Akhlaq — an independent IT-Consultant based in Darmstadt, Germany. I’ve been working in software engineering and architecture since 2011, and since 2018 I run my own consultancy imalik8088.

My sweet spot is the intersection of data engineering, streaming architectures, and cloud-native infrastructure. I help teams build reliable, scalable systems — from real-time Kafka pipelines to Kubernetes-based platforms — and I care a lot about doing it cleanly.

What I do#

Most of my work revolves around:

  • Streaming & Big Data — Apache Kafka (Kafka Streams, Kafka Connect, KSQL, Mirror Maker), Apache Flink, Debezium, Apache Pinot, Elasticsearch
  • Backend development — Java, Kotlin, Spring Boot, Quarkus
  • Cloud-native & DevOps — Kubernetes, Helm, ArgoCD, FluxCD, Terraform, GitLab CI, GitHub Actions, AWS
  • Data platforms — building and operating data lakes, real-time analytics platforms, and ML-ready infrastructure

I’ve worked across a wide range of industries: finance, insurance, automotive, telecom, energy, logistics, and retail.

Outside of work#

When I’m not in front of a terminal, I’m usually doing something active. Sports keep me sane.
